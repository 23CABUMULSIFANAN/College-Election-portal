# College Election Portal

A full-stack web application developed for conducting secure online college elections. The system allows admins to manage elections and students to cast votes securely through a responsive web interface.

## Features

- Admin and Student Authentication
- Candidate Management
- Secure Voting System
- Vote Counting and Result Publishing
- Duplicate Vote Prevention
- Responsive User Interface
- Backend API Integration
- MySQL Database Management

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Bootstrap

### Backend
- Python
- Django
- REST APIs

### Database
- MySQL
